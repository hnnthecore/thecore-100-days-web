Day 005 / 100 Phase 1 · UI Components

Login & Sign-up

Five authentication screens built the way serious products build them. They work with password managers, warn when Caps Lock is on, check password strength live, spot email typos, and handle wrong passwords and lockouts. Everything here is simulated in the browser. Real accounts arrive in Phase 4.

  • 5auth flows
  • Password-managerfriendly
  • One-timecode input
  • 0data sent anywhere

01

Lumen · Split-screen sign in

The standard SaaS sign-in, polished. It has single sign-on buttons, a show/hide password toggle, a Caps Lock warning, and “remember me”. A wrong password shows a clear error, and after three failed attempts a temporary lockout with a countdown kicks in.

  • Social sign-in
  • Caps Lock warning
  • Show password
  • Lockout countdown

Atlas · Sign up with password strength

Account creation that helps people succeed. It has a live strength meter and checklist, a block on very common passwords, an email-typo check (“Did you mean gmail.com?”), password confirmation, and a “check your inbox” screen with a resend timer.

  • Strength meter
  • Email typo fix
  • Common-password block
  • Verify-email screen

03

Nova · Passwordless code

No password to remember: enter an email and receive a 6-digit code. The code boxes jump forward as you type, accept a pasted code, support Backspace and arrow keys, fill automatically from SMS or email on phones, and submit as soon as the sixth digit is in.

  • 6-digit code
  • Paste & auto-submit
  • Resend timer
  • Autofill from SMS

04

Norde · Shop account with reset

An online-store account card where Sign in and Create account sit side by side as tabs. A built-in “Forgot password” flow sends a reset link without leaving the page. A guest checkout option keeps first-time buyers from abandoning their basket.

  • Sign in / Register tabs
  • Password reset flow
  • Guest checkout
  • Calm editorial style

Orbit · Sign-in modal

Let people browse first and ask them to sign in only when they want to do something, like saving or liking a post. The modal explains why it appeared and offers one-tap sign-in or email. Once signed in, the action they wanted completes automatically.

  • Accessible modal
