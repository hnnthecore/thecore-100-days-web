Day 014 / 100 Phase 1 · UI Components

Search bars

Six search bars that help people find things fast: suggestions as you type, recent searches, filters written as words, spelling help and honest loading and error states. All of them are fully usable with the keyboard.

01

Nova · Shop autocomplete

The online-shop search. Before you type, it shows recent and trending searches. As you type, it suggests completions and real products with prices. A category picker narrows everything down.

  • Combobox
  • Recent & trending
  • Product previews
  • Category scope

Click the box to see recent searches, then type “run” or “leather”. Use ↑ ↓ and Enter, or → to fill in a suggestion.

02

Wander · Travel booking search

The three-part search from hotel and holiday sites: where, when and who. Each part opens its own small panel, and finishing one moves you on to the next. On phones it stacks into a card.

  • Date chips
  • Guest steppers

03

Halden · Expanding header search

For sites where search shouldn't crowd the menu. A search icon in the header grows into a full-width search field over the menu, with quick links. Press “/” to open it from anywhere in the demo and Esc to close it.

  • “/” shortcut
  • Esc to close

    04

    Lumen · Filter-token search

    The power-user search from issue trackers and email. Type filters as words, like status:open or owner:riya, and they turn into chips. Suggestions help you write them, and the list filters live.

    • key:value filters
    • Chips
    • Smart suggestions
    • Live results

        05

        Ember · Live search with “Did you mean”

        Results update as you type, with matching words highlighted. Sort by what matters, and when you misspell something (“risoto”), it offers the right word instead of an empty page.

        • Search as you type
        • Highlighting
        • Spelling suggestions
        • Helpful empty state
        ember.kitchen/recipes

        Recipes

          Type “risoto” or “chiken”, then press the suggestion. Try a quick search chip or change Sort.

          06

          Atlas · Help-centre search (async)

          Real searches go to a server and take time. This one waits until you pause typing, shows a loading skeleton, ignores out-of-date answers, and handles errors with a Retry button. A microphone button appears in browsers that support voice input.

          • Debounced
          • Loading skeleton
          • Error + retry
          • Voice input

          Atlas Help Centre

          How can we help?

          Tip: search for to see what happens when the server fails.

          Type “domain” quickly and watch it wait for you to pause. Search “error”, then press Retry.
