Day 010 / 100 Phase 1 · UI Components

Product Cards

The card is where browsing turns into buying. Six patterns for shops, estate agents, restaurants, car dealers, luxury brands and app marketplaces, each with the interactions those customers expect: swatches, quick add, comparing, quick view and install states.

  • 6card patterns
  • Livebasket & order totals
  • Compare& quick view
  • Loadingskeleton states

06

Nova · App marketplace cards

Cards for integrations, plugins and templates. They load with skeleton placeholders (so the page never jumps), filter by category, and the Install button walks through real states: Install → Installing → Installed, with Remove available on hover.

  • Skeleton loading
  • Category filter
  • Install states
  • Ratings & installs
app.nova.so/integrations

Integrations

Watch the skeletons load, filter by “Developer”, then install an app. Hover an installed app to remove it.
