Day 013 / 100 Phase 1 · UI Components

Modals

Six dialogs that interrupt the user only when it's worth it: confirming something dangerous, finding anything fast, setting up an account, or editing and sharing without leaving the page. Each one traps focus, closes with Esc and returns you exactly where you were.

  • Focustrapped & restored

01

Halden · Type-to-confirm delete

For actions that can't be undone. The dialog spells out exactly what will be lost and asks you to type the project name. The red button only unlocks when it matches, then an Undo toast gives one last chance.
