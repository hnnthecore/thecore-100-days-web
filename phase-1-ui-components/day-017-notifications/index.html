Day 017 / 100 Phase 1 · UI Components

Notifications & alerts

Six ways to tell people what just happened, without nagging. Quick toasts, a notification centre, inline alerts, site banners, notification preferences and progress for long tasks. Every message is announced to screen readers and can be dismissed.

  • 6notification patterns
  • Liveregions
  • Undo& retry
  • Pauseon hover

01

Lumen · Toast system

Small messages that appear, stack and leave on their own. A progress line shows the time left, and it pauses while you hover or focus a toast. Toasts can carry an Undo, follow a slow task from “Saving…” to “Saved”, and be swiped away.

  • Stacking
  • Pause on hover
  • Promise toast
  • Swipe to dismiss

      Halden · Inline alerts

      Alerts that live inside the page, next to what they're about. Four tones (info, success, warning, error), each with its own icon so colour is never the only signal. Some have actions, some expandable details, and the form shows an error summary that links to each field.

      • 4 tones + icons
      • Actions
      • Expandable details
      • Error summary

        06

        Ember · Upload progress tray

        For long tasks that keep going while you work: a tray in the corner, like Google Drive's. Each file shows progress and time left, and can be paused, cancelled or retried. The tray collapses to a summary, and failures are explained.

        • Error + retry
