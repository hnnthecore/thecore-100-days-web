Day 015 / 100 Phase 1 · UI Components

Tables

Six tables for real data: sort, search, select, edit, expand and export. Each is a proper HTML table, so it reads correctly with screen readers. Each adapts to phones by stacking into cards, scrolling with sticky columns or hiding what matters least.

  • 6table patterns
  • Sortfilter & paginate
  • Editlike a spreadsheet
  • Exportto CSV

01

Lumen · Sortable data table

The classic admin table. Sort any column, search and filter, move through pages, and select rows (or the whole page) to export or delete them in one go, with Undo.

  • Sort (aria-sort)
  • Search + filter
  • Pagination
  • Bulk actions
app.lumen.app/customers

Customers

Customers, sortable. Use the column header buttons to sort.

Click a column header to sort (click again to reverse). Tick a few rows, then Delete and Undo.

02

Halden · Responsive invoice table

A table that turns into tidy cards on phones, keeping every label, instead of squeezing or scrolling. Status tabs with counts, a running “outstanding” total and one-tap reminders.

  • Table → cards
  • Status tabs
  • Totals footer
  • Row actions
halden.studio/invoices

Invoices

Outstanding (due + overdue)

Switch to Mobile to see the cards. Press “Remind” on an overdue invoice, or “Mark paid”.

03

Forge · Class timetable

A weekly schedule as a real table: times down the side, days across the top. Today is highlighted, filter chips fade out other class types, and tapping a class books a spot. On phones it scrolls sideways with the time column pinned.

  • Sticky column & header
  • Today highlight
  • Type filters
  • Book a spot
forge.fit/timetable

This week at Forge

No classes booked yet

Weekly class timetable

Tap a class to book (tap again to cancel). Filter by type. On Mobile, scroll sideways and the time column stays put.

04

Atlas · Editable budget grid

Spreadsheet-style editing. Move with the arrow keys, type a number to start editing, press Enter to save or Esc to cancel. Row totals, column totals and the remaining budget update instantly.

  • role="grid"
  • Arrow-key navigation
  • Inline editing
  • Live totals

Arrow keys move · type or Enter to edit · Esc cancels · values in £ thousands

Click a number, type a new value and press Enter. Use the arrow keys to move around.

05

Nova · Expandable order rows

Keep the table short and put the detail one click away. Each order expands to show its items, delivery address and a progress timeline, with actions right there. “Expand all” is useful for printing.

  • Expand / collapse
  • Nested detail
  • Order timeline
  • Expand all
admin.nova-store.com/orders

Orders

Recent orders. Each row can be expanded for details.
DetailsOrderCustomerStatusTotal

Press the arrow on a row to see its details. Try “Mark as shipped”.

06

Ember · Configurable report

A report people can shape themselves. Choose which columns to show, switch between compact and comfortable rows, and download exactly what you see as a CSV. The header and totals stay pinned while you scroll.

  • Column chooser
  • Density toggle
  • CSV export
  • Sticky header + totals
